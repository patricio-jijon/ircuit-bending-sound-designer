Learn

Hear the circuit relationship

A component does not have one universal sound. Its position in a circuit determines whether it changes gain, pitch, tone, clipping, or time.

Core vocabulary

Resistance
Opposition to current, measured in ohms (Ω). With a capacitor, it can also set timing or filtering.
Capacitance
Stored electric charge, measured in farads (F). It shapes how quickly voltage can change.
Clipping
Flattening a waveform when a circuit cannot reproduce its full amplitude, producing harmonics and distortion.
Feedback
Sending part of an output back to an input. It can create echoes, sustain, instability, or oscillation.

Reference: Texas Instruments NE555 datasheet. The audio modules are educational behavioral models, not complete construction schematics.

Build boundary

Disconnect power before changing any connection. Use a current-limited 9 V DC supply. Outputs are intended for a powered speaker, amplifier, or audio interface input, never a bare low-impedance speaker. Confirm breadboard rail continuity and polarized capacitor orientation before power-up.

Design challenge

From clean pulse to broken machine

  1. Add an oscillator and set a steady pitch.
  2. Add fuzz twice. Give each stage a different clipping material.
  3. Place octave before distortion, listen, then reverse their order.
  4. Add delay and increase feedback until repeats nearly sustain.
  5. Explain why changing the order changed the result.
Physical build safety

Use only 3.3–12 V DC. Disconnect power before rewiring, check polarized parts, and use a current-limited supply when practical.
